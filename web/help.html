Argo / Adapter Contract v1

统一提交 JSON，Rust Scheduler 选择执行节点，Worker 根据目标 Provider 适配 CLI 输入，执行输出以任务与事件记录返回。

任务示例

{
 "provider": "codex", "title": "Review login",
 "prompt": "Review and test login flow",
 "model": null, "repo_alias": "star",
 "target_node": null, "context": {}, "attachments": []
}

Multica

需指定 Workspace、Project 与 Agent；已有任务卡使用 Issue ID。Project、Issue、Agent 列表可从已授权的目标 Worker 通过其安装的 Multica CLI 查询。

Orca

需指定仓库 ID 和 Orca Agent。创建并启动后状态为 dispatched；不把 CLI 返回当成 Agent 执行完成。

Node

在每台计算机运行 argo-runtime worker。控制面由 argo-runtime server 运行。请参考 ZIP 中 README、设计文档与 tests。

安全

在公网部署时必须使用 HTTPS、反向代理及强随机 Token。Worker 机器本地持有各 Agent 自身认证信息。演示模式仅在 ?demo=1 时启用。
