# 安全、性能与故障注入测试设计

| 编号 | 输入 / 故障 | 检查项 |
|---|---|---|
| SEC-01 | XSS 脚本作为 RAG 标题/标签 | 前端转义输出，没有脚本执行 |
| SEC-02 | `../`、绝对路径、软链接逃逸 | JS 与 Rust 路径检查，不启动跨仓库执行 |
| SEC-03 | Worker Token 冒充 Admin | RAG/任务详情返回 401 |
| SEC-04 | Vercel Token 缺失 | HTTP 412，网络请求不发起 |
| SEC-05 | 恶意远端 301 重定向 | reqwest 不自动跟随 |
| SEC-06 | Prompt 内含 Shell metacharacters | 命令参数数组传递，不执行 Shell 插值 |
| SEC-07 | 含 Secrets 的 Agent 回执 | 基础 Redaction 生效；人工检查敏感信息泄漏 |
| SEC-08 | 旧 revision 覆盖新稿 | 返回 409，保留新版本 |
| SEC-09 | 同步时并发编辑 | 本地状态检查，返回并发冲突；运维对账 |
| SEC-10 | 失联 Worker | 租约到期 needs_review；不盲重试有副作用操作 |
| PERF-01 | 80k 中文字符导入 | ≤128片，无无限循环/超长片段 |
| PERF-02 | 2000+ 知识片段 | 当前上限返回2000扫描中的200；计划加游标与数据库索引 |
| PERF-03 | 3节点×各类 Agent | 考察内存、磁盘、CLI 并发、慢接口压力 |

开放缺口：真正 OS 沙箱、远端回滚/删除、内容审计日志、细粒度 RBAC、密钥轮换、跨节点写回审批、数据库批量分页。测试记录应注明平台、版本、输入、输出与缺陷修复状态。
