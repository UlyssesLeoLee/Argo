## 真实平台最小验证条件

各平台应先通过官方 `--version/--help`、认证检查、独立 CLI 手工试运行，再由 Argo 实际执行；尤其 Orca 必须先启动其 App/Serve，Multica 需 Workspace 写入和 Agent 分派权限。测试产生实际模型调用或写入操作时应使用临时 Project/Issue，避免对生产造成成本或数据副作用。
