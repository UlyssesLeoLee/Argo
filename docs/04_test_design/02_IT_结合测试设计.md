# IT 结合测试设计

| ID | 组合 | 前置 | 操作 | 预期 |
|---|---|---|---|---|
| IT-01 | UI→Controller→Worker | 1台节点在线 | Codex 任务 | 任务 queued/running/completed、事件可查 |
| IT-02 | 多节点调度 | 节点 A/B | 目标为 A | 只由 A 领取并执行 |
| IT-03 | 文件目标 | A 有 IDE1.0，B 也有同名仓库 | 选择 A 文件、B 执行 | 前后端拒绝，不误改 B 文件 |
| IT-04 | RAG 自动草稿 | 任务 rag_capture=true | 正常运行完成 | 创建任务来源分段、重复捕获不重复入库 |
| IT-05 | RAG 禁用采集 | rag_capture=false | 运行完成 | 无 RAG 记录；手动 capture 拒绝 |
| IT-06 | RAG 审核→同步 | HTTPS Mock 2xx | approved 后同步 | synced、remote_id 填充 |
| IT-07 | 远端失败 | Mock 5xx/超时 | 同步 | 保留 approved，记录失败状态 |
| IT-08 | 远端检索 | 可用 Vercel Search URL | 搜索 | 返回最多20个受限字段，允许导入本地草稿 |
| IT-09 | RAG 引用→任务 | 有 approved 片段 | 用户主动引用 | Agent Prompt 包含来源ID与正文 |
| IT-10 | Star 代理 | Star 服务端持有 Admin Token | 发任务/查结果 | Web 终端不出现敏感 Token |

需求真实双机、第三方 CLI 和数据库环境；代码中的 DEMO 模式不能替代本套 IT 验收。
