# Argo UT 单体测试设计书

ID：ARGO-TD-UT-001 · 版本：1.0 · 方法：white-box + 输入等价类/边界值

## 单测目标与执行环境

测试 `model.rs::validate`、`model.rs::invocation`、JS `lib.mjs` 等纯函数，不依赖外部模型服务。命令：`node --test tests/ui.contract.test.mjs`、`cargo test --workspace`。当前制作环境执行通过的只有 JS 10 项，Rust 工具链未安装，不能虚报 Rust UT 通过。

| UT ID | 对象 | 输入/步骤 | 预期结果 | 实现映射 |
|---|---|---|---|---|
| UT-001 | Providers | 枚举 | 6 个唯一 Provider ID | ui.contract.test.mjs |
| UT-002 | TaskForm | 正常标题、Prompt、Codex | null（合法） | ui.contract.test.mjs |
| UT-003 | TaskForm | Prompt 为空/空格 | 提示任务目标必填 | ui.contract.test.mjs |
| UT-004 | OrcaValidator | 仅 Repo ID；再增加 Agent | 先拒绝再接受 | ui.contract.test.mjs |
| UT-005 | MulticaValidator | 缺 Workspace/Agent/Project | 先拒绝再接受 | ui.contract.test.mjs |
| UT-006 | PromptPreservation | 特殊字符/多行/命令符 | 文本原样保留，不执行 | ui.contract.test.mjs |

## 判定规则

每一条用例必须记录执行机器、工具版本、输入/期望/实际、PASS/FAIL、缺陷 ID。未执行的用例标记 NOT RUN。不可将存在测试文件解释为已全部执行通过。
