# UT 单体测试设计

| ID | 对象 | 输入 | 期待 |
|---|---|---|---|
| UT-01 | Agent目录 | 六个平台 | 恰好6种、无重复ID |
| UT-02 | 标准 Task | 合法 Prompt | 验证通过，数据不经 Shell 插值 |
| UT-03 | Orca | 缺 repo/agent | 提示缺少平台专属参数 |
| UT-04 | Multica | 缺 Workspace/Project/Assignee | 拒绝任务 |
| UT-05 | RAG 分段 | 2000 汉字/emoji | 各片 <=850 字符，Unicode 不截断 |
| UT-06 | RAG 脱敏 | Bearer/API Key | 敏感字符串替换为 [REDACTED] |
| UT-07 | RAG 指纹 | 重复原文 | 相同来源内容相同指纹，数据库幂等 |
| UT-08 | 状态流转 | draft→approved→synced | 只有 approved 可以上传 |
| UT-09 | 审核变更 | synced 后编辑 | 重回 draft，禁止未经审核直接写回 |
| UT-10 | 并发保存 | 旧 revision 提交 | 返回 409，不覆盖新修订 |
| UT-11 | 知识链接 | 自引用/非法类型 | 拒绝 |
| UT-12 | 文件 scope | `../secret` / 绝对路径 | 前后端均拒绝 |
| UT-13 | 跨机文件修改 | owner=A, run=B, repo非空 | 拒绝 |
| UT-14 | 引用上下文 | 2条已批准片段 | 带 `[Argo-RAG:id]` 的参考块 |
| UT-15 | HTML 转义 | 来源包含脚本标签 | 作为文本而非 HTML 执行 |

执行：`node --test tests/ui.contract.test.mjs tests/rag.contract.test.mjs`；Rust `cargo test -p argo-runtime` 需本地安装 Rust 工具链。本交付环境未实际完成 Rust 编译。
