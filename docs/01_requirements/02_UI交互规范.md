# Argo v0.2 前端与视觉交互规范

## 1. 视觉主题

采用美漫 3 渲 2（cel shading）**轻量表达**而非满屏插画：奶油色纸张 `#F8F4EC`、墨蓝 `#152A43`、少量明黄 `#FBC75A`、蓝绿色 `#2C8992`、警示红 `#BF513F`。主交互色只在当前 Tab、执行按钮与确认动作出现。边框约 1.5–2px、硬边阴影 2–3px；网点仅局部出现，避免文字和字段背景被装饰侵占。阿尔戈号船徽仅位于标题栏，不画人物；神庙和浪花保留为微小主题线索。

## 2. 设计理论约束

- **Gestalt 邻近律**：文件机器→仓库→路径逐级缩进并同组包裹；执行机器另为卡片，决不与路径平级。
- **Hick–Hyman 选择成本**：六种 Agent 用互斥选项卡，一次只渲染一个表单。
- **Progressive Disclosure**：模型、标题、审查、上下文采集放高级设置；风险提示按条件出现。
- **Recognition over Recall**：平台专属字段具有示例、现有任务卡/创建新卡模式；记住用户上次会话设置时不得自动使用未验证路径。
- **视觉层级**：顶栏（选择项目/连接）→六 Agent Tab →主输入→文件归属→执行→输出；RAG 管理独立页面。
- **状态无色盲依赖**：颜色配合明确文字（待审/已批准/已入库/已归档）。
- **动效**：不连续闪烁；hover 仅 1px 位移，执行状态以标签表现。

## 3. 导航

主导航：执行任务、任务记录、个人 RAG、机器与集群、设置；不重复在主区域设置第二层项目选项卡。个人 RAG 内左侧状态类别、中央搜索列表、右侧检查器，顶部导入与远端检索；筛选项随需要展示但不强制填写。

## 4. 六平台输入状态

| 平台 | 必要字段 | 默认不显示 |
|---|---|---|
| Claude | 指令 | 模型、审批、RAG 引用 |
| Codex | 指令 | sandbox/审查、模型 |
| Hermes | 指令 | Skills/工具开关、模型 |
| Orca | Repo ID、内部 Agent、指令 | 工作树 CLI 细节、模型参数 |
| MiniMax | 指令 | Runtime/模型设置 |
| Multica | Workspace、Project/Issue、Assignee、指令 | 发现/创建策略、远端同步 |

## 5. 状态与异常

- 失去节点连接：禁用执行或显示具体错误，不显示绿色“成功”。
- 文件机器与运行机器不同且选择了仓库：阻止提交并说明跨机写回仍需审核同步机制。
- RAG 审核时：编辑内容后回退为 draft；已入库内容修改形成待重新审核状态。
- Vercel 未配置：本地分段归档仍可用，远端同步/搜索给出可操作错误。
- 任务来源的异步派发：Orca/Multica 使用 dispatched 状态，而不是 completed。

## 6. Tauri 与 Web

Tauri 2 以相同 `web/` UI 构建桌面壳层，通过原生 IPC 代理 `argo_request` 调用本地或 HTTPS Controller。浏览器调试使用 `python -m http.server 8899 --directory web` 和 `?demo=1`。平台支持配置及命令由 Rust Worker 决定，浏览器不能直接执行 Shell。
