## 3. 关键残留风险

1. **工作目录不是强沙箱**：Agent 可以按其进程权限访问文件系统/网络；建议受信机器运行或额外接容器隔离。
2. **节点信任**：所有 Worker 使用共享 Token；节点身份不是独立签发证书；只用于受信集群。
3. **多机快照是 Git HEAD，不是实时文件系统共享**；大于 40 MiB 的工作集需缩小范围；不会同步未提交源更改。
4. **人工确认不等于生产安全审计**：patch/README/脚本内容仍应进行 SAST、测试和授权检查，不能自动信任 Agent 输出。
5. **Windows 配置文件 Secret**：位于用户 AppData，保存了本地 Controller Token 与连接器 Secret；应依赖用户文件权限、磁盘加密，并在未来增加 Windows DPAPI / 凭据管理器。
6. **新平台 STAR**：只有 webhook 接收契约；无法确认未发布产品的真实接口或执行完成状态。
7. **兼容性**：第三方工具版本变动会影响 CLI 参数；由本地安装环境预检并更新适配器。
8. **分批修改**：当前全库处理由前端驱动，界面关闭后不会继续；重启后需重新选择剩余数据，部分完成可在修订历史中审查。
