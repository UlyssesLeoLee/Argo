# Argo v0.5 安全架构详细设计与运行手顺

## 1. 守护进程与前端

Tauri 2 管理 Rust Sidecar 生命周期，TypeScript 仅访问 Tauri IPC，不持有本机管理员密钥。WebView 只允许 `core:default`。运行时 Backend、Worker 仍独立 Rust 程序，构建后以同一 Sidecar binary 的 `server` / `worker` 子命令启动。

## 2. 节点身份与凭据

**新部署首选：节点单独密钥**。

Controller 环境示例（将下面占位 token 替换为独立随机 32+ 字符；通过加密配置或 OS Secret 管理）：

```powershell
$env:ARGO_BIND = '127.0.0.1:8788'
$env:ARGO_ADMIN_TOKEN = '<unique-admin-token-at-least-24-chars>'
$env:ARGO_WORKER_TOKEN = '<unused-legacy-token-at-least-24-chars>'
$env:ARGO_NODE_TOKENS_JSON = '{"machine-a":"<unique-node-a-token-at-least-24-chars>","machine-b":"<unique-node-b-token-at-least-24-chars>"}'
argo-runtime server
```

Worker A：

```powershell
$env:ARGO_SERVER = 'https://controller.example.com'
$env:ARGO_NODE_ID = 'machine-a'
$env:ARGO_WORKER_TOKEN = '<unique-node-a-token-at-least-24-chars>'
$env:ARGO_REPOS_JSON = '{"star":"D:\\projects\\Star"}'
argo-runtime worker
```

Worker B 设置 `machine-b` 和对应独立 Token。跨主机时控制面前方必须有经验证的 HTTPS 代理或私有 VPN 隧道，不直接暴露明文 HTTP。每个 ID 为 ASCII 字母数字、`-`、`_`，最多 100 字节。Token 如被泄露，修改 Controller 的节点密钥配置和对应 Worker 密钥并重启；当前不支持自动轮换。

**个人单机模式**：Tauri 仅绑定 `127.0.0.1:18788`，显式设置 `ARGO_ALLOW_SHARED_WORKER_TOKEN=1` 启用旧接口兼容；Controller 在非回环绑定下永不允许共享身份模式。不要将单机模式提升为远程部署。

## 3. 批量 AI 改写事务

`POST /api/v1/ai/preview` 获取模型输出并在 `rag_ai_previews` 写入一次性 `preview_id`，有效 600 秒。前端展示全部变更后用户确认 `POST /api/v1/ai/apply`，提交 `preview_id + operation + changes + confirm=true`。Controller 在同一 SQLite transaction 内比较保存的 JSON 与请求 JSON、检查 revision、记录旧快照、更新为 `draft`、消费预览 ID。重复/篡改/超时一律拒绝。超过 8 条先生成下一批次预览。

注意：多批之间**不是**全库原子事务。窗口关闭或 API 失败时已成功提交的批次仍存在，需要按修订历史核查，并可逐条恢复；生产级全库事务编排仍待设计。

## 4. Git 文件权限边界

- Owner worker 从 clean `HEAD` 出口按路径导出 tar 快照，带 SHA-256，绝不传递整个 `.git` 目录。
- Executor 在临时工作区运行可用 Agent，执行结果经 Diff artifact 上传。
- 审核人看完整 Diff（超过 200KB 不能在 UI 直接批准），确认 sha 一致后生成独立 review Worktree。
- 不能执行 `git apply` 到源检出目录；HEAD 改变需人工调解。
- `argo_file_scope` 目前是 Git 审计和路径规范，**不是 OS 沙箱**。Agent 子进程可能仍有源宿主用户权限；不可信任务不得放行。

## 5. 安装与验证

```powershell
npm install
npm run check:all
python tests/smoke_snapshot_patch.py
python tests/adversarial_git_protocol.py
cargo test -p argo-runtime
cargo check -p argo-desktop
python tests/integration_cluster.py
npm run build
```

没有 Rust / Windows 编译环境时可以验证前端，但不得宣称桌面安装包已通过。前端演示 `npm run preview`，浏览器打开 `http://127.0.0.1:8899/?demo=1`。
