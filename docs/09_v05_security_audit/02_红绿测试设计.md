## IT（结合）

- IT-01：启动 Controller A 和 Worker A/B，并配置不同 `ARGO_NODE_TOKENS_JSON`；尝试用 B Token 发送 A 的 `node_id`，期待 HTTP 401。
- IT-02：从 A 的 `src/` 导出 tar 到 B，确保 `private.txt` 不传输，B 产生 patch，A 仅在 review worktree 中应用。
- IT-03：租约超过 90 秒再提交结果；期待拒绝，任务转 `needs_review`，不自动重跑。
- IT-04：AI `preview` 后篡改 `changes`、重复 apply、过期 apply、并发 revision；无数据不一致。
- IT-05：用 `source_head` 与实际 HEAD 不符的补丁申请回写；必须拒绝。
- IT-06：RAG 多连接器中某个响应 500 / 超时；其他记录不应被误标同步成功。

## ST / E2E（系统）

- ST-01：Windows 安装 EXE/MSI，首次运行自动启动 Sidecar；关闭时回收子进程。
- ST-02：两机真实运行不同 Agent，能选择文件属主、执行节点，且真实产物不触及属主工作目录。
- ST-03：七平台逐个现场验证版本号、输入模式、任务卡与 CLI 行为；STAR 仅验证接收回执，不宣称任务完成。
- ST-04：RAG 1000 条记忆分批预览、筛选、标签、统一改写、版本恢复和多服务商连接。
- ST-05：用户主动禁用自动采集，确认任何模型输出不会自动入库或同步外部 RAG。
