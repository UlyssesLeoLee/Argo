# Argo 交付自审与差距清单（最终状态）

ID：ARGO-QA-001 · 版本：1.0

## 已核查一致性

1. 项目名称从 ASTER 统一变更为 **Argo**；无对原 ASTER 项目的运行依赖。
2. 六平台名称/ID 与 UI、后端模型验证、Worker CLI 命令表一致；MiniMax Code 用 `mcode` 而不是凭空构造 `minimax` 命令。
3. Orca 的内置 CLI 用 Worktree/Agent 形式启动，不将其误视为独立 LLM API。
4. Multica 的 Workspace/Project/Issue/Agent 用对应 CLI 意义处理；已有 Issue 采用二阶段评论→assign，任何一步失败都不伪报完成。
5. 任务状态 `dispatched` 与真正完成 `completed` 严格分离。
6. 文件输入/输出由 SHA-256 引用和 Blob 存储管理；不声称具备透明显存/内存合并。
7. 运行目录按任务隔离，默认仓库逻辑别名在 Worker 本地解析，不允许浏览器直接指定任意路径。
8. 前端有连接、错误提示、必要字段校验、Demo 明确区分、取消与结果下载。
9. Node.js 前端 10 项测试实际执行通过，未执行的 Rust 相关测试如实标注。
